# AI world interaction assets

The PNG illustrations in this folder come from the Google Noto Emoji project and are bundled locally so the learning interaction works offline.

- Source: https://github.com/googlefonts/noto-emoji
- License: Apache License 2.0 (see `LICENSE.txt`)
- Retrieved: 2026-07-30
- Files: U+1F431, U+1F415, U+1F697, U+1F34E, U+1F4F7, U+1F6B2

The app applies blur locally at render time. No student image is collected or uploaded.
